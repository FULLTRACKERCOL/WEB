# FULLTRACKERCOL — paquete completo de hosting
Web pública + registro/login + demo 3 días + dashboard + admin + API PHP inicial + documentación.
Sube el contenido a public_html. Cambia la clave de config/config.php antes de producción.
Para GPS real despliega el Gateway TCP/UDP en un VPS y conecta API/WebSocket. Para pagos, mapas, IA, Dashcam y apps móviles debes configurar sus servicios reales.
